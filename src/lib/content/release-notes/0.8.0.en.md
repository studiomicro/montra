- A fresh look: Montra now uses the Geist typeface, the phone layout has a slimmer tab bar with a round Tambah button, and Koko the mascot got a cuter redraw.
- Agent (beta) for the Agent plan: ask for a report on your records and get it as a file to download, kept for 30 days. It needs your own Anthropic key and is not available to use yet.
- Tidier screens everywhere: a back link on every inner page, the settings gear on the phone top bar, Impor in one card, input fields with a clear outline, and a better fit on small iPhones.
- Excel files from heavily edited workbooks (many validation or formatting rules) now import instead of being refused.
- Fixed: cancelling a scan on Impor now stops it straight away, and disconnecting Gmail removes everything it read.
