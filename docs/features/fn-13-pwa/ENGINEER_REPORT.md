## Decisions beyond the PRD (recorded, adopt or overrule)

1. **Sending is implemented, not deferred.** RFC 8291 (aes128gcm) and RFC 8292 (ES256 JWT) on WebCrypto; no
   dependency. Verified byte for byte against the RFC 8291 Appendix A vector and the RFC 8292 example
   signature; real push-service delivery is **not** tested (see gaps).
2. **Push-service host allowlist** (`validation.ts`): FCM (`fcm.googleapis.com`, `android.googleapis.com`),
   Mozilla (`updates.push.services.mozilla.com`), WNS (`*.notify.windows.com`), Apple (`web.push.apple.com`);
   https, default port, no credentials. Stops a crafted subscription from making the Worker POST anywhere
   (SSRF). A browser on another push service is refused with a message.
3. **Subscriptions are bound to the session** (`session_id`): sign-out tombstones that session's rows without
   needing the client (works without JS). Account deletion hard-deletes all rows.
4. **Endpoint takeover rule:** the same endpoint posted by another user updates the row only if it is a
   tombstone or its session is no longer live (browser changed hands); otherwise 409. Cap: 20 live rows per
   user (one guarded `INSERT … SELECT … WHERE count < 20 ON CONFLICT … WHERE …` statement).
5. **`Clear-Site-Data: "cache", "storage"` on sign-out and account deletion:** drops Cache Storage, the service
   worker and with it the browser's push subscription, plus session/local storage. Cookies are left to the
   action (theme/lang stay). Future FN-02 local data will be cleared by this too, which is the intended
   shared-device behaviour, but FN-02 should know.
6. **Enhanced sign-out does a full page load** (`location.assign`) instead of a client-side `goto`: otherwise
   the signed-out tab still held the account page's SSR hydration payload (found by the e2e probe).
7. **QR target is `${origin}/pengaturan/instal`, not the bare origin** (criterion 4 says `url.origin`): the
   bare origin lands a signed-out phone on `/masuk`, not on the instructions the PRD says it should reach.
8. **`/pengaturan/instal` is public** via an exact route-id allowlist in `gate.ts`; signed out it renders inside
   the app shell (tab links lead to sign-in).
9. **`wrangler.jsonc` `html_handling: "none"`:** Workers static assets otherwise 307 `/offline.html` → `/offline`,
   and a redirected response cannot answer a navigation from the service worker.
10. **Install button** lives on `/pengaturan/instal` only (captured by the root layout); it is hidden in in-app
    browsers. `isPushConfigured` is true only for a complete, well-formed key set.
11. **Notification page reads its own state client-side** and gets only SHA-256 hashes of the user's endpoints
    from the server (the other devices' endpoints never reach the page).

- **L1** `listActiveSubscriptions(db, userId, now)` returns only rows whose session is still live (not revoked, not
  expired). In the same `db.batch` it tombstones the user's rows whose session ended. The 20-device cap no longer
  counts those rows.
- **L2** `normalizePushEndpoint` (`src/lib/shared/push.ts`) lower-cases the scheme and host and drops `:443` and a
  trailing host dot. Path and query are kept byte for byte, and other ports, credentials and fragments are refused.
  Subscribe stores this form, unsubscribe compares it, `isPushEndpoint` only accepts it, and the page hashes its own
  endpoint in it.
- **L3** The push `fetch` uses `redirect: 'manual'`, so a 3xx becomes `PushSendError` and the row stays.
- **L4** A root `_headers` file, which adapter-cloudflare copies into the build:
  - every static asset gets nosniff, a referrer policy, HSTS and COOP;
  - `/offline.html` also gets a script-free CSP with `frame-ancestors 'none'` and `X-Frame-Options: DENY`.
  - `scripts/e2e-build.sh` now rebuilds when `_headers` changes. This also covers the FN-00 TASKS item "static
    assets get no security headers" for the asset paths.
